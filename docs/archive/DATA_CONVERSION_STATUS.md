## Known scoring caveats

- **MOp `obs/Cluster` is a `class_label` proxy**, not true anatomical Allen CCF region. The proxy enables landmark + region-overlap metrics under `sabench_light_alignment_v1`, but absolute numbers are not directly comparable to the paper's `region_overlap_ratio` for true CCF subregions. Affects `sa-020`, `sa-021`, `sa-101..sa-112`.
- **WMB labels (`obs/Region`)** for `sa-023` come from the Allen CCF parcellation **substructure** — the most granular CCF level. Different vocabulary (~688 categories) than the cluster-based labels in MOp; they are not cross-comparable.
- **MAE coordinate-scale mismatch**: paper Source Data MOESM10 reports Flysta3D and MLN MAE in source-capture-pixel units (102-192 for Flysta3D, hundreds-to-thousands for MLN); our compiled slices use atlas-aligned coords with smaller spans, so our absolute MAE values are not directly comparable to the paper's per-method MAE numbers. Re-compiling with `obs/x_GT, y_GT` set to source-capture coords would fix the comparability if needed.
